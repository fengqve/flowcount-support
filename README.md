# Footfall Tally / 客流计

站在候选铺位或场所入口，按实际观察手动计数。每轮默认 15 分钟，保存轮次，再比较同一地点不同时段的记录。

Manually count passing footfall or venue visits in 15-minute rounds on iPhone.

**平台 / Platform:** iPhone
